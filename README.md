# Personal Portfolio Website

A modern and fully responsive personal portfolio built with React and Tailwind CSS to showcase my skills, projects, and professional profile. The website features a clean UI, smooth navigation, interactive animations, and reusable component architecture to provide an engaging user experience across all devices.

It includes a dynamic hero section with a typewriter animation, an interactive skills slider, project filtering by category, responsive project cards, social media integration, and a contact section designed to present my work in a professional and user-friendly way.
